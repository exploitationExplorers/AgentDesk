关键发现

  • 原生 Agent 能力的骨架已经完整：多轮工具调用、原生文件编辑、真实 diff、审批、桌面编码现场、长期记忆均已有基础实现——不是"从零开始"的项目。
  • 差距集中在"深度"而非"有无"：权限只覆盖 Shell、压缩缺 micro 层、子代理无隔离、技能字段兼容不全——这些是同一能力域里"从部分到完整"的工作，不是全新建设。
  • 两个完全空白的能力域：MCP、通用 Hook 生命周期系统，两者都需要独立立项，不能靠改几个入口文案宣称已对齐。
  • 文档会过期：本页已发现并修正一处（S05 长会话压缩），说明 docs/claude-code-parity/ 的结论需要定期用实际代码复核，不能当作永久真相。
