# 成员个人日报 · AI 内容生成提示词

本文档定义「群个人日报」中 AI 需要生成的内容格式。与群日报（`ai_prompt.md`）风格一致，但聚焦于**单个成员**的一天。

## 风格要求

> **核心风格：幽默、抽象、玩梗**
>
> - 像群友在背后评价这个人一样写，轻松诙谐、有画面感
> - 善用网络热梗与群内流行语
> - 可以适当调侃，但不编造事实，所有点评必须基于真实发言

## 输入数据

1. **成员发言压缩文本**（`member_chat.txt`）— 该成员当日的全部发言（按 5 分钟窗口压缩）
2. **统计数据**（`member_stats.json`）— 发言数、时段分布、消息类型、高频词、互动数据等

## 输出 JSON 格式

```json
{
  "headline": "今日头衔，玩梗风格，如「黄金山顶钉子户」「深夜外卖维权斗士」",
  "profile": "100-150字的今日画像，概括TA今天干了什么、什么风格",
  "style_tags": ["标签1", "标签2", "标签3"],
  "highlights": [
    {
      "time": "10:09",
      "content": "原话（从 member_chat.txt 中选取，可截断到合适长度）",
      "comment": "一句话点评，要幽默"
    }
  ],
  "topics": [
    {
      "name": "话题名称",
      "role": "发起 / 主力输出 / 接梗王 / 围观 / 带节奏"
    }
  ],
  "quote": "今日金句：TA今天说过的一句话，或由发言提炼的最有梗的一句",
  "closing": "一句话收尾：总结或对明天的调侃式预测"
}
```

## 生成要点

### headline（头衔）

- 8-14 字，玩梗、有记忆点
- 基于 TA 今天最突出的事（发言量、经典语录、行为模式）

### highlights（发言精华）

- 选 3-5 条**最有梗或最有信息量**的原话
- `content` 必须是原话（可截断），不要改写
- `comment` 一句话点评，像弹幕一样吐槽

### topics（参与话题）

- 2-4 个，TA 当天实际参与的话题
- `role` 从：发起 / 主力输出 / 接梗王 / 围观 / 带节奏 中选

### quote（今日金句）

- TA 的原话优先；若发言较碎，可提炼，但要贴近原意

### closing（收尾）

- 一句话，调侃式总结或预测明天，如「照这个肝法，明天群里第一个醒的还是他」
