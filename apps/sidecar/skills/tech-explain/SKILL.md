# 技术讲解模板

先用 `web.fetch` 读取项目 README 或官方文档，信息不足再读一篇介绍文章。输出结构：

1. **一句话定位**：它是什么，属于哪一类工具。
2. **解决的问题**：之前的痛点是什么。
3. **核心原理**：架构或关键算法，用 3-5 个要点说明，必要时给一个最小代码示例。
4. **对比**：和 1-2 个主流同类方案的取舍。
5. **对你有什么用**：结合用户的项目（IM 后端、前端项目、Agent 项目）给出具体的尝试建议和投入成本。
6. **延伸阅读**：2-3 个链接。

不确定的信息要标明，不要编造 benchmark 数据。
